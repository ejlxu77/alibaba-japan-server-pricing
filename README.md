## 常见问题

**日本服务器需要备案吗？**
不需要。日本属于海外地域，不涉及大陆的备案流程，轻量应用服务器官方明确免备案。

**200M峰值带宽是真的200M吗？**
是峰值速率，突发时可以跑到200M，持续大流量传输时速率会回落。固定1Mbps是全天保证的速率，峰值200M是上限能力，两者定位不同。对网站访问这类流量，峰值方案的实际体验通常更好。

**一年价格以后续费会涨吗？**

**国际站的日本套餐价格和国内站一样吗？**
不一样。阿里云国际站以美元计价，其日本节点活动页展示的参考价为：入门型1核1G（40G高效云盘，含Windows系统）年付180.4美元，进阶型1核2G年付326.9美元，通用型2核4G年付608.3美元，理想型4核8G年付2053.1美元。国际站与国内站分属两套账户和计价体系，下单前以页面实时价格为准。
